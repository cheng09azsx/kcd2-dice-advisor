# KCD2 骰子参谋

离线单页工具，用来在《天国：拯救 2》的骰子（Farkle）对局里做拿法、收手和胜率决策。

- 在线版：https://cheng09azsx.github.io/kcd2-dice-advisor/
- GitHub：https://github.com/cheng09azsx/kcd2-dice-advisor

## 直接使用

双击根目录的 **KCD2骰子参谋.html** 即可，不需要联网、不需要安装、不需要服务器。手机可以直接打开在线版，或只把这一份 HTML 传到手机。

页面会把对局、骰组和设置保存在浏览器 localStorage 中；换浏览器不会同步。

## 已实现

- 目标分、我方分数、对手分数、先后手状态。
- 双方各 6 颗骰子，可逐颗设置不同概率；内置 36 种 KCD2 骰子预设。
- 每颗骰子下方可直接切换骰型；点「手动录入」可逐颗填点数。
- 可得分组合按胜率列在主桌面上，金框标出推荐；点组合即可在骰桌上选中。
- 推荐拿法：枚举所有合法得分组合，比较「拿走并续掷」与「收手」的胜率。
- 自动风险预算：系统用 `B = clamp(8% + max(0, 续掷胜率 - 收手胜率), 8%, 35%)` 动态控制爆点风险，不需要手动挡位。
- 本回合累计分数可直接修正；胜率、自动预算、下一掷爆点实时更新。
- 自动记分、热骰重置、爆点、对手回合记录、撤销、新对局。
- 桌面端和手机浏览器自适应；手机端为单屏决策模式（360×640、375×667、390×844 实测无需滚动），隐藏说明、侧栏和页脚，只保留比分、骰子、组合和操作。
- 手机端开启手动录入时，用录入区替换组合/按钮区，仍然保持单屏。

## 规则细节

- 单 1 = 100，单 5 = 50。
- 三条：1 为 1000，2-6 为点数 × 100；四/五/六条按三条分数连续翻倍。
- 小顺 1-5 = 500，大顺 2-6 = 750，全顺 1-6 = 1500。
- **三对子不算分**。
- KCD2 **没有掷骰次数上限**，直到主动收手或爆点。
- 6 颗骰子全部得分后全部回到场上（热骰），可继续掷。
- 爆点会失去本回合累计分数，不会扣总分。

## 算法说明

- 先给一个**快速估算**（双方固定收手阈值的竞速模型），界面立即可用。
- 随后在后台求解**双方最优的精确博弈解**：每个剩余分数状态都枚举所有合法拿法，并比较续掷 / 收手，迭代到千分之一容差；求解完成后胜率与推荐会自动更新，并标注「精确博弈」。
- 当前回合内的拿法同样是精确动态规划，不只是看单次得分。
- 推荐层再加一道**自动风险预算**：`B = clamp(8% + max(0, 最佳续掷胜率 - 最佳收手胜率), 8%, 35%)`。续掷的下一掷爆点超过 B 时自动改为收手；这是约束 MDP 的 ε-约束，不需要手动挡位。
- 自动预算会随当前牌面的胜率差动态变化：续掷优势越大，允许的爆点风险越高；优势很小时优先收手。
- 六颗骰子完全不同、目标分很大等复杂情况会保留快速估算，避免长时间阻塞。
- 胜率是模型估计，不是游戏内定值；用于比较行动，不保证与真实对局频率完全一致。

## 参考

- Busche, M., Neller, T. W. (2017). *Optimal Play of the Farkle Dice Game*. Advances in Computer Games, LNCS 10664, 63–72. [DOI](https://doi.org/10.1007/978-3-319-71649-7_6)
- Altman, E. (1999). *Constrained Markov Decision Processes*. Chapman & Hall/CRC.
- Rockafellar, R. T., Uryasev, S. (2000). *Optimization of Conditional Value-at-Risk*. Journal of Risk 2(3), 21–41.

自动风险预算不改变双方的精确胜率表，只改变当前推荐动作；界面显示的胜率仍是该动作的原始胜率。它会用极小的理论胜率换取更低的爆点率。

## 已知限制

- 首版只建模「逐面非均匀概率」的特殊骰。
- 魔鬼头颅骰的万能面、徽章、改点等非概率效果**未计入**；魔鬼头颅预设当前按普通六面概率计算，界面会提示。
- 复杂骰组可能只使用快速估算；界面会标注「快速估算」。
- 精确求解默认按 50 分状态网格，约需数秒；可以先按快速估算操作，完成后结果会自动替换。

```bash
pnpm install

pnpm test        # 规则 / 模型 / 拿法测试
pnpm build       # 生成单文件 dist/index.html
pnpm build:pages # 构建并同步 docs/index.html（GitHub Pages）
```
